Host Application Page

This page demonstrates Phase 9: Embeddable JavaScript Widget. Notice there is no React or build tool on this page—only a plain HTML document loading the compiled IIFE script. 

<!-- Include widget styles -->
<link rel="stylesheet" href="style.css">

<!-- Include standalone widget script -->
<script src="agentic-kb-widget.iife.js"></script>

<script>
  const widget = AgenticKB.init({
    apiUrl: 'http://localhost:8000',
    assistantName: 'Enterprise Data Assistant',
    theme: 'dark',
    position: 'bottom-right',
    showSources: true,
    enableStreaming: true
  });
</script>

Look at the bottom-right corner of this page to interact with the floating AI database chatbot.
